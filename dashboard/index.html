    About the data

    Contribution counts come from the public GitHub calendar and are refreshed daily by the profile workflow; the snapshot time is in the top bar. The activity feed loads live from the public GitHub API when the page opens and falls back to the latest workflow snapshot. Streaks count consecutive days with at least one contribution; if today has none yet, the current streak counts up to yesterday. These are activity indicators, not a measure of code quality.
