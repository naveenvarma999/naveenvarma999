About these numbers & data freshness
  • Contribution counts come from the public GitHub calendar. GitHub defines what counts as a contribution; this is not a count of every commit or a measure of hours worked.
  • The snapshot date appears at the top. Charts update after the supplied GitHub workflow is installed and runs successfully. This page does not poll GitHub while you browse.
  • Date filters change contributions, streaks, weekday totals, trend and landscape. Repository and language figures describe the full account snapshot.
  • A streak is consecutive active days within the selected range. Comparison uses an equally long immediately preceding range only when that entire range is present in the data.
  • Bar height represents contribution count. Motion is visual only. Values never animate to invented data.
  • CSV exports all daily records in the selected range. Zero-contribution days are included. Repository language counts are not language proficiency scores.
